## About

I'm Shanudha Tirosh, a self-taught developer in Sri Lanka. I build software and the platforms around it: web apps with React, Next.js and Firebase, WhatsApp bots on Baileys, Android apps in Kotlin with Jetpack Compose, and IoT hardware on ESP8266 with MQTT.

I also handle the server side. I set up VPN and proxy servers on Xray, put them behind Nginx and Cloudflare, and script the Linux installs. I build for the local market too, with Sinhala-language support and Sri Lankan payment methods such as HelaPay and eZcash.

I ship working systems instead of prototypes. On Android I use MVVM. With Firebase I design cache-first, with offline persistence. Bots are structured as plugins so features can be added without touching the core. Interfaces get a dark, glassmorphic design system.

Right now I'm exploring Docker and Proxmox, Supabase and PostgreSQL, LiveKit for real-time communication, and AI automation with MCP-based agents.

My work ships under the **ShanuFx** and **ShanuTechX** brands. ShanuTechX is also where I publish VPN setups, Android root guides, bot development and open-source drops. Company site: [info.shanutechx.com](https://info.shanutechx.com/).
